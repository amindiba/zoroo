## 📋 درباره پروژه

**زورو | چشم بازار** یک پلتفرم هوشمند برای نظارت و خرید محصولات صنعتی و ماشین‌آلات تولیدی است که به صورت تخصصی بر روی:

- ✅ نظارت دقیق روی قیمت‌ها و نوسانات بازار
- ✅ بررسی تولیدکنندگان ایرانی (فقط تولیدکننده)
- ✅ رصد تولید، کیفیت و عرضه محصول
- ✅ نظرسنجی‌های مرتبط با تولیدکننده و محصولات
- ✅ جستجوی هوشمند بر اساس نیاز مشتری
- ✅ مقایسه و پیشنهاد بهترین گزینه‌ها
- ✅ واسطه‌گری خرید و پیگیری گارانتی

تمرکز دارد.

## 🚀 ویژگی‌های فنی

### تکنولوژی‌های استفاده شده

#### Backend
- **PHP 8.2+** - آخرین نسخه پایدار PHP
- **WordPress 6.4+** - سیستم مدیریت محتوا

- **React 18+** - برای بخش‌های تعاملی
- **TypeScript** - کدنویسی نوع‌گرا
- **Tailwind CSS 3.4+** - استایل‌دهی مدرن
- **Vite** - بیلد سریع و بهینه
- **Next.js 14+** - برای صفحات داینامیک

#### ابزارهای توسعه
- **Composer** - مدیریت وابستگی‌های PHP
- **npm/yarn** - مدیریت پکیج‌های JavaScript
- **ESLint + Prettier** - استانداردسازی کد
- **PHPUnit** - تست‌نویسی PHP
- **Jest** - تست‌نویسی JavaScript

## 🛠️ نصب و راه‌اندازی

### پیش‌نیازها
- PHP 8.2 یا بالاتر
- WordPress 6.4 یا بالاتر
- Node.js 18+ و npm/yarn
- Composer 2+

### مراحل نصب

1. **کلون کردن مخزن**
```bash
git clone <repository-url> zoro-theme
cd zoro-theme
```

2. **نصب وابستگی‌های PHP**
```bash
composer install
```

3. **نصب وابستگی‌های JavaScript**
```bash
npm install
# یا
yarn install
```

4. **ساخت فایل‌ها برای تولید**
```bash
npm run build
# یا
yarn build
```

5. **فعال‌سازی در وردپرس**
   - پوشه `zoro-theme` را در `/wp-content/themes/` کپی کنید
   - از پیشخوان وردپرس، قالب را فعال کنید
